# Image-Scene-Classifier
> 基于Python的图像分类程序，识别图片为风景、美食、人像三大类别
> Python image classification program to identify images into three categories: landscape, food and portrait.

## 📖 项目简介
本项目为自研Python图像分类脚本，可对输入图片进行自动分类，区分**风景、美食、人像**三类场景。
项目包含图像推理代码，可直接运行用于图片批量识别。
> ⚠️ 本项目仅用于个人技术学习与实验，请勿用于商业用途。

> This is a self-developed Python image classification script. It can automatically classify input images and distinguish three scene types: landscape, food and portrait.
> This project includes image inference code and supports batch recognition of images.
> ⚠️ This project is only for personal technical learning and experiments. Commercial use is prohibited.

## ✨ 功能特性
- ✅ 支持单张图片识别
- ✅ 支持批量图片分类
- ✅ 输出图片类别结果：风景 / 美食 / 人像
- ✅ Python脚本，跨平台运行

> Features
- ✅ Support single image recognition
- ✅ Support batch image classification
- ✅ Output category: landscape / food / portrait
- ✅ Python script, cross-platform
